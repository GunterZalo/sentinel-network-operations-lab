
# Sentinel — Network Operations Lab

## Project Overview

Sentinel is a hands-on networking and Linux system
administration project designed to simulate a small
enterprise network infrastructure.

The project focuses on developing practical skills
in network configuration, Linux administration,
AAA authentication, monitoring and troubleshooting.

## Objectives

- Deploy and configure a small network infrastructure.
- Administer Linux servers and network devices.
- Implement centralized authentication with RADIUS.
- Configure network monitoring and alerting.
- Document troubleshooting procedures and incidents.
- Practice Git version control.

## Technologies

- Cisco CML or GNS3
- Linux (Ubuntu / Alpine)
- SSH
- FreeRADIUS
- Zabbix
- Git and GitHub
